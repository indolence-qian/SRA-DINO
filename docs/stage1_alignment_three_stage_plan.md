# 一阶段三阶段实验协议：语义分支、对齐继承与正常参考

状态：协议对应的核心 H/T/R 模式已有独立实现，入口 `run_exp_alignment_stages.sh`；
具体运行、续跑与输出说明见 [运行文档](alignment_stages_running.md)。编号不能作为旧 v1 CLI 的参数。
新实现不改变 v1 代码、权重、封存缓存或已有结果；本地验证不代表真实工业实验已经运行。

## 1. 问题与范围

已有结果提示：冻结 Base 的高分辨率读出有定位收益，但训练后的新头出现跨域退化。
本轮依次回答三个问题：

1. 文本分支是否被有效使用，还是隐藏特征直通路径在主导分数修正？
2. 显式继承原 Adapter 的特征关系、推迟跨尺度融合，是否能减轻退化？
3. 在稳定前端之上，正常参考证据是否有独立收益，置信门控能否减少干扰？

前两阶段不使用正常参考；第三阶段才增加参考。三阶段均不训练 DINO、HFA、CLIP、
原 Prompt Learner 或原 Patch/Prompt Adapter，不引入 RL、VLM、dino.txt。
机制风险不等于已证明的原因；不能预先把实验解释为“对齐成功”或“必然涨点”。

## 2. 全部阶段共同固定的条件

| 项目 | 固定值或要求 |
|---|---|
| Base | 与 v1 同一份 `14.pth`，记录完整 SHA256 |
| 数据 | 同一 VisA source train/val 内容家族划分；同一目标查询集合 |
| 图像 | 全局 512；原图 2x2 重叠切块，宽高占比 0.6；每块输入 512 |
| 高分辨率融合 | global/local 权重 0.75/0.25；本轮不同时搜索切块密度或 beta |
| 输出与 GT | 评价 512；沿用 v1 最近邻 mask 与阈值定义 |
| 原视觉层 | 5、11、17、23；保持同一精度与预处理 |
| 有效 batch | 8，micro-batch 2；相同 query 顺序和优化步数 |
| 优化 | AdamW，初始 LR 1e-4，weight decay 0.01；15 轮固定调度 |
| 筛选与确认 | 先统一训练 5 轮，再让候选及其关键对照一起续至 15 轮 |
| 修正强度 | alpha 集合预先固定为 0、0.05、0.1、0.25、0.5、1 |
| 源域分割损失 | BCE + 正例 Dice；背景抬升约束权重 1；修正量约束权重 0.01 |
| 语义辅助损失 | 保留文本分支时权重 0.1；明确移除文本的消融除外 |
| 随机因素 | 数据划分、参考池、固定投影的种子始终 42；训练初始化种子另行设置 |

训练种子首轮为 42；进入正式确认的可学习候选及其关键对照再用 43、44 重复。
原脚本把多个随机因素绑在一个 `SEED` 中；下一版实现需要拆分这些种子，不能直接改旧 SEED
同时改变划分、参考池、随机压缩，再把差值称为训练随机性。
冻结 Base 的确定性读出不需要为了“凑三种子”重复同一个结果。

所有组记录参数量、训练 FLOPs/耗时、端到端推理耗时与显存；架构消融存在参数量差异时明确报告。
晚融合使用同一份小头共享处理各个视图，不给五个视图分别建立独立参数。

## 3. 选模、阈值与防止目标测试反馈

主选模规则在本轮训练前固定，不沿用只看 BCE+Dice 的单一规则：

1. 每个 epoch、每个 alpha 都只在 source val 评价类别宏平均 PRO 与 pixel AP。
2. 始终包含 epoch=0/alpha=0 的对应冻结读出。
3. 候选须同时不低于冻结读出的 source PRO 和 AP，且至少一项严格提高；否则回退冻结读出。
4. 合格候选依次按 PRO 高、AP 高、alpha 小、epoch 早排序。使用未四舍五入的数值。
5. 源域背景 FPR=1% 的操作阈值仅用 source val 校准，跨目标复用；不承诺目标 FPR 相同。

额外保留 v1 的“source BCE+Dice 最小”选择器作为预先约定的诊断对照。
同一条训练轨迹分别应用这两种规则，报告两者各自选中的 epoch/alpha；不能再从两者中
挑目标测试分数较高的一套作为主结果。只改选择器不会改变训练梯度，适合单独分析选模错配。

第 5 轮的阶段决策只使用 source 结果和源域机制诊断。进入 15 轮的候选及其关键对照须一起续跑，
不能用“15 轮候选 vs 5 轮对照”声称架构优势。若没有合格学习候选，保留冻结高分辨率 Base，
仍可继续参考距离的诊断，但不默认叠加更多可训练模块。

目标预测先生成并锁定，再读取目标 mask 评价。目标不参与梯度、早停、alpha、阈值、损失权重或
参考选择。MVTec、BTAD、MPDD 已用于方案诊断，应在论文中视为开发过程中的目标基准，不能再
声称它们完全未影响方法设计；最终还需要未参与方案选择的独立目标验证。
已有 Base 可能见过 source val，不能把这份 source val 当成 Base 从未见过的独立泛化证据。

## 4. 阶段一：文本分支与隐藏特征直通路径

目的：不加正常参考，区分“文本接口没有帮助”和“最终修正没有依赖文本接口”。

设 h 为同一 CNN 融合的隐藏特征，z=normalize(W h+b)，
m=20*z^T*(t_abnormal-t_normal)。除下表明确改变的部分外，输入、卷积骨架、损失与预算不变。

| 编号 | 文本分支 | 最终修正量 | 作用 |
|---|---|---|---|
| H0 | 冻结 Base 原有文本读出 | delta=0 | 冻结高分辨率基线 |
| H1 | 当前新增文本投影，语义 BCE=0.1 | delta=w_h^T*h+w_m*m+b | 重现 v1 的 B_highres |
| H2 | 删除新增 to_text、margin 和语义辅助损失 | delta=w_h^T*h+b | 测试整个新增文本组件的净作用 |
| H3 | 与 H1 相同文本投影、语义 BCE=0.1 | delta=gamma*m+b，不读取 h | 强制空间修正经由文本 margin 产生 |

H1/H2 最后输出层零初始化；H3 的 gamma、b 均零初始化，保证开始时与 H0 相同。
H3 不等于完整 CLIP 语义对齐：m 仍只有一个正常/异常判别方向。其目的只是去掉隐藏特征捷径。
H2 删除的是整个新增语义组件，不是只将 `SEMANTIC_WEIGHT` 置零。

若 H2 与 H1 存在稳定差异，再补 H1_aux0：保留原结构和 margin 通路，只关闭语义辅助损失。
H1_aux0 不是首轮必跑项，用于进一步分开“分支作用”与“辅助损失作用”。

### 阶段一诊断

- 每轮保存权重，而不只保存 best/last；记录全部 source 指标与两套选模结果。
- 在 source 正常像素/异常像素分别统计 delta 的中位数、分位数、正负比例与幅度。
- 单独评价 m 的像素 AUROC/AP，以及最终修正后的指标；H3 记录 gamma、b。
- 对已有第 5 轮权重预先固定 alpha 扫描，比较修正强度与退化的关系；目标扫描只作为诊断曲线。
- 记录 h 通路与 margin 通路对 delta 的贡献，以及对应权重/梯度；不把相关性当成因果证明。
- 正常图上的错误修改面积与异常图上的缺陷改善/损失分开报告。

解释边界：H2 优于 H1 只表明当前语义组件不利；H3 优于 H1 才支持“直通修正可能有害”。
若三种学习头均退化，优先检查源域适配、表示瓶颈和选模，不将问题简化为“CLIP 不适合”。

## 5. 阶段二：原 Adapter 特征保持与跨尺度融合位置

目的：在 H3 的同一语义修正骨架上，测试完整特征约束，以及全局/局部何时融合。
不使用正常参考，不同时更换随机压缩维度、优化器或文本塔。

### 冻结教师与保持损失

教师不是一个新的训练模型，而是原 Base 的逐图标准化 + 已训练 Patch Adapter。
每个视图提取四层 768 维归一化特征，再归一化其层平均，作为对应位置的教师 Z_Base。
教师只前向、stop-gradient；它保留的是原 Adapter 的特征关系，不只是两个文本相似度标量。

新增保持损失：L_keep=mean[1-cos(z_new, Z_Base)]。
仅在 source GT 完全正常的空间单元上计算；用区域覆盖率排除含任何异常像素的单元，
不要用最近邻下采样把小缺陷消掉后误当正常。正常图也纳入这项损失。
lambda_keep 固定为 0 或 0.1；目标 mask 不用于保持损失。

### 四组受控对照

| 编号 | 保持损失 lambda_keep | 融合位置 | 与谁比较 |
|---|---:|---|---|
| T00 | 0 | 特征先融合，再做文本投影/修正 | 与 H3 相同计算，应做一致性校验 |
| T10 | 0.1 | 特征先融合，再做文本投影/修正 | T10-T00：保持约束的作用 |
| T01 | 0 | 每个视图独立投影/修正，最后拼接概率图 | T01-T00：晚融合的作用 |
| T11 | 0.1 | 每个视图独立投影/修正，最后拼接概率图 | 与 T10/T01 比较及交互分析 |

早融合教师同样按 global/local=0.75/0.25 在原图坐标融合后归一化。
晚融合在每个视图自己的网格上比较学生/教师，各视图的 loss 先按视图内正常位置求均值，
再以全局 0.75、四个局部各 0.25/4 聚合，避免局部视图数量隐式放大保持损失。
晚融合先对每个视图的原 Base 概率图施加同一共享头的修正，然后按原坐标 Hann 拼接并固定加权。
其局部坐标始终用原图坐标，不能把每个 crop 都错误地重新标为完整原图。

所有方案 delta=0/alpha=0 时都必须恢复各自对应的冻结高分辨率输出。晚融合与早融合的
训练 query 数和更新步数相同，但 head 前向计算量不同，需实际计时，不能声称等计算量。

本阶段的“继承”通过冻结教师的特征约束完成，并非已将完整原 Adapter 特征替换为学生输入。
若结果仍提示压缩瓶颈，再独立追加 64 vs 256 的压缩维度实验，其他设置不变，需要重新导出；
不能把教师、晚融合和更大维度同时修改，再把总差值归因于任意一项。

T00 与已有 H3 可在实现与数值一致时复用；其他三组为新增训练。
阶段二关注 source PRO/AP、正常特征漂移及三种子的稳定性，不只看 L_keep 是否下降。
若保持损失下降而检测未改善，应报告“更接近教师但未转化为检测收益”。

## 6. 阶段三：正常残差的独立增益与置信门控

先按 source 规则锁定阶段二候选 P0；若没有合格候选，P0 就是冻结高分辨率 Base。
该前端在阶段三冻结，各参考方法使用相同 P0，不能一组使用新头而另一组使用旧头。

参考协议保持 v1：同类别正常 TRAIN 图，4 图池中检索 1 张，排除查询同图及解码 RGB 重复，
空间半径 0.35、top-3 soft matching。参考不从目标 TEST 的已知正常图选择。

先输出查询-参考的匹配位置、带符号残差、距离与熵，再做下面的增量对照：

| 编号 | 参考证据的使用 | 是否新增训练 | 目的 |
|---|---|---|---|
| R0 | 不使用参考，输出 P0 | 否 | 阶段三共同基线 |
| R1 | 标准化距离图作为固定分数修正 | 否，仅 source 选固定强度 | 检查证据本身能否使用 |
| R2 | 相同残差分支预测修正，固定门值 0.5 | 是，仅训练残差分支 | 检查可学习残差接口 |
| R3 | 与 R2 相同残差分支，增加置信门 g | 是，残差分支及门 | 检查置信筛选是否减少参考干扰 |

R1 的各层距离先按固定等权汇总；用 source 训练正常像素的全局中位数和分位距做固定中心化/
尺度归一化，再用 source val 选择 lambda=0/0.05/0.1/0.25/0.5。退化分位距须明确报错。
不做依赖目标 mask 的归一化，也不做逐张图 min-max 后再声称分数已跨图校准。
概念式为 logit(P_R1)=logit(P0)+lambda*d_standardized；数值实现沿用 identity-safe 修正。

R2/R3 读取相同的压缩残差、匹配参考、距离和熵，预测 delta_ref；已有 query 主干与小头均冻结。
R3 的门只读取匹配距离、熵、检索相似度等推理时可得量，g 属于 [0,1]、初始化为 0.5；
R2 固定门同为 0.5，使两组初始缩放一致。残差输出末层零初始化。
二者均使用 P=sigmoid(logit(P0)+alpha*g*delta_ref) 的稳定实现。
不能把“低 top-k 熵”直接当成正确对应：门必须在 source 训练，效果需用 R3-R2 验证。

R2/R3 使用相同分割、背景与修正量约束，不添加不对称的新语义辅助任务；任何此类增加另立消融。
这里测试的是正常参考证据的增量利用，不把一个预测分数修正的残差分支称为完整的 CLIP 文本对齐。
R0/R1 无训练种子；参考池固定。R2/R3 做相同的训练种子对照。参考池随机性若研究，另开实验。

优先做固定类别面板：hazelnut、screw、grid、connector、BTAD 03，以及这些类别的正常图。
类别已由本轮开发结果选出，不能把其可视化称为盲选验证；类别内图片由确定性哈希抽样，
在查看新模型结果前固定 ID，不只挑成功案例。

若 R1 的距离证据本身缺乏区分能力，应先研究参考选择/对应，而不是继续增加分支容量。
若 R2 有收益而 R3 没有，应报告门控未产生额外收益。若 R3 仅召回提高但误报升高，
不能仅凭命中数宣称参考质量改善。
参考数量 1 vs 4 和匹配半径消融仅在上述机制明确后追加，不与首轮门控一起搜索。
R 系列使用目标类别正常 TRAIN 支持，始终属于参考辅助设置，不称为严格无参考零样本。

## 7. 主结果和机制结果

每个数据集分别给出类别宏平均与逐类别增量，不用不同类别数的混合平均替代。

- 主指标：PRO-30、pixel AP；辅助指标：pixel AUROC、image AUROC。
- 操作点：source 校准阈值下的目标背景 FPR、像素召回、小连通域命中/恢复/丢失。
- 公平诊断：目标固定 FPR=1% 的小连通域召回，用评价曲线报告；该阈值只用于评价，
  不反过来选择部署阈值、alpha 或模型。小连通域定义仍为图像面积 <=0.1%，至少 10% 像素命中。
- 机制：margin、delta、特征漂移、门值、参考身份和匹配可视化，正常与异常样本分开统计。
- 稳定性：三训练种子的均值/标准差、逐类别升降。需要置信区间时按图像配对重采样，
  再计算类别宏平均，不能将相关像素视为独立样本。训练种子变异与数据抽样区间分开报告。
- 成本：包含冻结编码与必要参考处理的端到端耗时；缓存参考与首次建立参考池的成本分别列出。
  小头自身耗时不能当成整套模型速度。

新增结果表必须记录 run_id、实验编号、父配置、完整权重/缓存/代码哈希、各随机种子、
完成轮次、所选 epoch/alpha、选择器、参考支持数量、参数量和 fallback 标志。
fallback 结果与成功学习结果分开统计，不能把回退当作新模块的增益。

## 8. 缓存、实施边界和实际工作量

1. H 系列在输入协议完全一致时，可通过新的只读消费者使用 v1 查询特征、先验和概率图。
   现有封存目录及代码哈希不能改写；新训练结果、模型定义与选择器必须放到新实验目录。
2. 旧 v1 脚本不支持 H2/H3、特征保持、逐视图晚融合或 R3 门控；使用新的三阶段入口，不能靠改旧环境变量完成。
3. 当前 v1 缓存只有已拼接局部证据和 64 维压缩特征，无法反推出完整 768 维教师或各个原始 tile。
   阶段二需补导出逐视图 64 维查询特征、先验、Base 图、坐标，以及 source 的 768 维教师；
   教师只用于 source 训练/诊断，不要求目标部署时额外执行教师网络。
4. 阶段三需要逐视图残差/匹配证据以及检索相似度；不同融合方式必须使用同一份可核验的导出。
5. v1 只留 best/last 时，历史 JSON 不能重建第 1~4 轮权重。已有 B 的第 5 轮可作诊断点，
   但按新选择器比较完整轨迹时需补齐同协议轨迹，必要时公平重训 H1。
6. 新实现先测 identity、文本分支确实移除/直通确实切断、teacher stop-gradient、正常 mask
   单元选择、tile 原坐标、source-only 选模、目标 mask 隔离、缓存哈希与断点恢复。

首轮机制筛选：H1/H2/H3 三组；T00 复用 H3 后 T10/T01/T11 三组；R2/R3 两组。
因此核心为最多 8 条学习轨迹（每条先 5 轮），加冻结读出和不训练的 R1 距离诊断；
已存在的完整等价轨迹可减少重训。若阶段检查不通过则停止扩大该分支，不承诺八组必然全部运行。
15 轮和三种子只对 source 选出的候选及其必要对照执行。最终独立目标验证在方法和配置锁定后进行。
